Cookies and browser storage

Last updated: 11 October 2026

What this website adds

The SCREEPYOS website code does not set cookies, use localStorage or sessionStorage, or include advertising, analytics, tracking pixels, social embeds or embedded videos. Fonts and artwork are served with the website. There is no advertising or analytics consent banner because these features are not used.

Hosting and external links

GitHub Pages serves this website and records visitor IP addresses for security. This is separate from cookies set by our website code. See GitHub’s hosting information and GitHub’s privacy statement. If you follow a link to GitHub, AME or another website, its own privacy and cookie practices apply.

If this changes

Non-essential tracking or third-party embeds must be assessed and, where required, kept disabled until valid consent is given. Rejecting and withdrawing consent must be as easy as accepting it. This notice must be updated before such features are introduced.
