Accessibility

Last updated: 11 October 2026

We aim to make the website usable with a keyboard, at different screen sizes and with reduced motion. This is a progress statement, not a certification of complete WCAG compliance.

Features

  • Skip-to-content link, semantic headings and named navigation.
  • Visible keyboard focus, native buttons and expandable sections.
  • Reduced-motion support, improved text contrast and wrapping layouts.
  • Decorative artwork is hidden from assistive technology; relevant meaning is present as text.
  • No website forms, CAPTCHA or time-limited interactions.

Scope and limitations

This statement covers the download website, not the Windows dashboard, AME Wizard or external websites. Full screen-reader, assistive-technology and WCAG conformance testing has not been completed.

Report a barrier

Report a technical accessibility problem through GitHub Issues (public, GitHub account required). Describe the page, browser, assistive technology and what you expected. Please do not include private device information in a public issue.
